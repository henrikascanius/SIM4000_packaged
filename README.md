# SIM4000_packaged
Install-and-run RC4000 emulator with disk image

Can run under Dosbox-X (recommended), and Dosbox. Config files for both are included; you need to edit the last few lines to suit your installation.

Once the (virtual) DOS environment is up, go to the CTRL dir and type RC<cr>

Also runs in VirtualBox with FreeDos, but lack of file system integration is a problem.
